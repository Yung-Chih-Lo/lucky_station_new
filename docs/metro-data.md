## 更新既有資料庫

部署前先備份資料庫。Docker entrypoint 會依序執行 Drizzle migration、MRT seed 與台鐵 seed。`0003_metro_layout_20260925` 是一次性資料遷移：將當時已存在的 MRT 站點示意座標、站名標籤與連線路徑改為此版路網排版，並將畫布設為 1600 × 1880。遷移只以 MRT 中文站名及連線端點／路線比對，不變更 ID、名稱、經緯度、抽站紀錄或留言。新站與新連線隨後由 seed 加入。

Seed 以 MRT 中文站名找到既有站點，保留資料庫 ID 與管理者調整。新增站點的來源 ID 若已被台鐵或其他站點使用，改分配新的 ID；路線關聯與連線均使用實際資料庫 ID，保留既有抽站和留言。一般 seed 只擴大畫布，不縮小；重複執行不增加重複資料。遷移記錄確保新版排版只套用一次，日後重新部署不會覆蓋管理者後續調整的位置。

若日後需要手動將路網位置重設為當前來源 JSON，備份資料庫後執行 `npm run seed -- --layout`。這是管理用操作，會再次覆蓋既有 MRT 座標、站名標籤、連線路徑與畫布尺寸。
